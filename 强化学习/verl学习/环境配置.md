## verl环境安装

[Github项目地址](https://github.com/verl-project/verl) [文档地址](https://verl.readthedocs.io/en/latest/index.html)

### 系统环境要求

- **Python**：Version≥3.10
- **CUDA**：Version≥12.8

### 训练和推理后端

- **训练**：**FSDP**和**Megatron-LM**（可选）
- **推理**：**SGLang**，**vLLM**和**TGI**

### 本地环境配置

> 因为我的环境没有nvidia runtime，所以无法使用docker，这里只使用conda配置环境

```bash
conda create -n verl python==3.12
conda activate verl
git clone git@github.com:verl-project/verl.git
cd verl
# 训练只使用FSDP
USE_MEGATRON=0 bash scripts/install_vllm_sglang_mcore.sh
pip install --no-deps -e .
```

中间安装包可能比较慢，耐心等待，如果无法下载，可以手动下载再上传，然后运行verl给的案例，在训练完成后遇到报错

```text
AttributeError: '_thread.RLock' object has no attribute '_recursion_count'
```

**解决办法**

```bash
pip install 'multiprocess==0.70.11'
```
